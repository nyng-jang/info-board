짧은 확인 방법

  1. 어디로 가나요? 이 페이지
  2. 3단계 이내 행동 ① 접속 → ② 「합성 재생」에서 TIMEOUT 선택 → ③ 「다시 시도」 클릭
  3. 무엇이 보이면 통과인가요? ②에서 마지막 정상값이 그대로 남고 「Stale」 배지와 timeout 안내가 뜬다. ③ 뒤에는 「Fresh」, 오류 코드 none, 일별 기록이 1건 늘어난다.
  4. 안 될 때 무엇이 보이나요? 값은 지워지지 않고 「Stale / 오래된 값」 배지와 실패 종류·마지막 시도 시각이 표시된다. 정상값이 한 번도 없으면 「오류 · 저장된 값 없음」이 보인다.
